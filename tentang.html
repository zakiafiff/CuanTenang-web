Tentang CuanTenang

Kebijakan privasi

  • Situs ini tidak meminta akun dan tidak menyimpan data keuanganmu. Template diunduh lalu diisi di perangkatmu sendiri.
  • Kalkulator menghitung langsung di browsermu. Angka yang kamu ketik tidak dikirim ke server kami.
  • Situs memuat font dari Google Fonts dan grafik dari TradingView. Penyedia tersebut dapat memproses data teknis seperti alamat IP sesuai kebijakan privasi masing-masing.
  • Penyedia hosting situs ini dapat mencatat log kunjungan standar (misalnya alamat IP dan waktu akses).
  • Karena datamu ada di file milikmu, simpan salinan (backup) berkala dan jaga file yang berisi data sensitif.
